# AGENTS.md

Instrucciones para agentes de IA que trabajen en `clinica-demo`.

## Qué es este proyecto

Aplicación web de una clínica ficticia: reserva de citas, recepción, agenda de especialistas, documentos y mensajes. Java 17 con Spring Boot. Los datos son de ejemplo y viven en memoria (H2).

## Cómo compilar y arrancar

- Requiere JDK 17 o superior.
- Compilar: `./mvnw -B compile`
- Arrancar: `./mvnw spring-boot:run`
